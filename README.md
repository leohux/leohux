### About

I build systems where **AI meets capital markets** — event-driven architectures, LLM agents, and trading infrastructure that is safe by construction. I care about clean abstractions, hard risk gates, and code that behaves exactly as designed under pressure.

我做的是 **AI 与金融市场的交叉** —— 事件驱动架构、LLM 智能体、以及「默认安全」的交易基础设施。信奉干净的抽象、硬性风控闸门，以及在压力下依然可控的代码。
